# BudgetBasics — React Application

Personal Finance Portal for University Students built with React 18 and Vite.

## Quick Start

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation
```bash
npm install
```

### Run Development Server
```bash
npm run dev
```
Open your browser at `http://localhost:3000` or the URL shown in your terminal.

### Production Build
```bash
npm run build
```
This generates production-ready optimized static files in the `dist` folder.

### Preview Production Build
```bash
npm run preview
```
